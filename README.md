# NLBB Web (PWA)

This folder contains the React PWA migration target for NLBB.

## Source of Truth
Migration scope, progress, and next steps are tracked in:
- `../PWA_MIGRATION_PLAN.md`

## Commands
- `npm run dev`
- `npm run build`
- `npm run preview`

## Environment
- Copy `.env.example` to `.env` and set `VITE_API_BASE_URL` if needed.
